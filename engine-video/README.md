# شلون يشتغل محرك السيارة 🔧

فيديو شرح عمودي (1080×1920، ‏33 ثانية) بلهجة عراقية، بستايل «بلوبرنت» هندسي: مقطع عرضي لأسطوانة محرك رباعي الأشواط.

| الوقت | المشهد |
|---|---|
| 0:00 | الهوك: «بمحرك سيارتك تصير… عشرات الانفجارات بالثانية 💥» |
| 0:03 | «خلّي نفتح المحرك… ونشوف» — الكرنك يبطئ ويوقف |
| 0:06 | تسمية الأجزاء: البوجي، بلف السحب، بلف العادم، البستن، ذراع التوصيل، الكرنك |
| 0:08 | الأشواط الأربعة بالتصوير البطيء: ١ السحب · ٢ الضغط · ٣ الانفجار · ٤ العادم |
| 0:25 | المحرك يتسارع + عداد الدورات: «مئات وحتى آلاف المرات بالدقيقة» |
| 0:29 | الكرنك يدوّر العجلة: «يوصل للعجلات 🛞» |

الأرقام صحيحة: محرك ٤ سلندرات على السلانسي (~800 دورة/دقيقة) يسوي ~27 انفجار بالثانية، وكل أسطوانة تكمل دورة كل لفتين للكرنك (يعني 400 إلى آلاف الدورات بالدقيقة).
الرسم مبسّط للشرح (ناقل الحركة بين الكرنك والعجلة مرسوم كسير).

## الملفات
- `index.html` + `src/engine.js` — التحريك (SVG + GSAP، كل شي محسوب من زاوية الكرنك فقط فيطلع حتمي).
- `render/soundtrack_engine.py` — الموسيقى والمؤثرات (ضربة لكل انفجار، شرارة وانفجار كبير بالشوط الثالث، سحب هوا، ضغط، عادم، صوت محرك يتسارع).
- `vo/script.md` — نص التعليق الصوتي مع التوقيت.

## الرندر
```bash
cd engine-video
node ../orin-ad/render/render.mjs --page ../engine-video/index.html --shutter 5
```
الناتج: `out/engine-video-9x16-60fps.mp4` (ونسخة 30fps).
