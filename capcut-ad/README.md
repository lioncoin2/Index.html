# إعلان حساب كاب كات برو (1080×1920، 24 ثانية، لهجة عراقية)

الفيديو: `out/capcut-ad-9x16-30fps.mp4` و `out/capcut-ad-9x16-60fps.mp4`.

| الوقت | المشهد |
|---|---|
| 0–3.2 ث | محرّر فيديو على موبايل — «خلصت المونتاج…» ← تصدير ← تنضرب العلامة المائية: «وطلعتلك العلامة المائية؟ 😤» |
| 3.2–7.1 ث | الأدوات تتقفل وحدة وحدة — «وكل الأدوات الحلوة… مقفولة 🔒» ← «هاي الأداة تحتاج برو» |
| 7.1–10.4 ث | «والاشتراك يريد فيزا 💳 ومنين تجيبها؟» ← الدفع «مرفوض ❌» |
| 10.4–15.5 ث | «لا تحتار… الحل عدنا 👇» ← الأقفال تنكسر، العلامة المائية تنمسح، «برو 👑» — «حساب كاب كات برو، كل شي مفتوح وبلا علامة مائية» |
| 15.5–20 ث | «شهر كامل… بـ 6 آلاف بس!»: بس 6 آلاف · مضمون شهر كامل · تسليم فوري · لجهاز واحد بس |
| 20–24 ث | «اطلبه هسة 👇» — واتساب / انستغرام |

الاسم مكتوب بالعربي وما مرسوم أي لوگو رسمي. التصدير:
`node ../orin-ad/render/render.mjs --page ../capcut-ad/index.html --shutter 5`

## الإعلان الثاني (`v2.html`) — ستايل جديد بالكامل

الفيديو: `out/capcut-ad-v2-9x16-30fps.mp4` و `out/capcut-ad-v2-9x16-60fps.mp4` (22 ثانية).
**الستايل:** كتابة حركية ضخمة (Kinetic typography) بالأسود والأخضر الليموني، كل كلمة تنضرب على الإيقاع،
والخلفية تتقلب أسود/ليموني/أبيض ويا كل قطع، وأشرطة نص متحركة، وموسيقى فونك (808 + كاوبيل).
**الهوك:** «لا تشترك بكاب كات برو 🚫… گبل ما تشوف هذا 👀» (أسلوب «لا تشتري گبل ما تشوف» + عرض النتيجة أولاً)،
والكاميرا تدخل من العيون للكشف: «حساب كاب كات برو جاهز» ← «6 آلاف بس!».

| الوقت | المشهد |
|---|---|
| 0–3 ث | «لا تشترك» ← «بكاب كات برو» ← 🚫 ← «گبل ما تشوف هذا» ← 👀 |
| 3–6 ث | «حساب كاب كات / برو 👑 / جاهز» ← «6 آلاف» ← «بس!» |
| 6–11 ث | «بدون برو؟» علامة مائية ✗ أدوات مقفولة ✗ ← «ويا حسابنا ✅» مسحة تشيل العلامة المائية ← «برو 👑» |
| 11–15 ث | 💳 بلا فيزا · ⚡ تسليم فوري · 🛡️ مضمون شهر كامل · 📱 لجهاز واحد |
| 15–17 ث | «شهر كامل / 6 آلاف» |
| 17–22 ث | «اطلبه هسة 👇» — واتساب / انستغرام |

التصدير: `node ../orin-ad/render/render.mjs --page ../capcut-ad/v2.html --shutter 5`
