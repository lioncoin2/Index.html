# شلون يشتغل المحرك — نسخة Anatomy

نفس فيديو شرح المحرك (عمودي 1080×1920، 35 ثانية، لهجة عراقية)، بس الرسم مبني بسكل **anatomy**
(`.claude/skills/anatomy`): مقطع نصفي أيزومتري لمحرك بانزين رباعي الأشواط على قاعدة، بتظليل الكِت
بأربع درجات وثيم الورق الفاتح. القطعة اللي يتكلم عنها النص تتلوّن بالبرتقالي.

## الملفات
- `build.mjs` — يبني الرسم بالكِت (`iso-kit.mjs` و`lathe.mjs`) ويكتب `src/art.js` (طبقات ثابتة + شكل الكرنك والذراع والغاز لكل نصف درجة). شغّله قبل الرندر: `node build.mjs`.
- `index.html` + `src/engine.js` — التحريك: كل شي محسوب من زاوية الكرنك `deg(t)`.
- `render/soundtrack_engine.py` — نفس صوت النسخة الأولى (ضربة لكل انفجار).

## الرندر
```bash
cd engine-anatomy && node build.mjs
node ../orin-ad/render/render.mjs --page ../engine-anatomy/index.html --shutter 5
```

ملاحظة صادقة: سرعة «الدوران السريع» بالفيديو 300 دورة/دقيقة تقريباً (مبطّأة للعرض، ومكتوب «عرض مبطّأ» بالزاوية)؛ المحرك الحقيقي أسرع بكثير.
