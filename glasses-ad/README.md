## الإعلان الثاني: المشكلة والحل (`v2.html`)

الفيديو: `out/glasses-ad-v2-9x16-30fps.mp4` و `out/glasses-ad-v2-9x16-60fps.mp4` (25 ثانية). ستايل مختلف تماماً:
كرتون «بوب» بألوان مسطحة وحدود سودة عريضة وظلال صلبة، وشخصية مرسومة بالكود.

| الوقت | المشهد |
|---|---|
| 0–3.2 ث | الهوك: لقطة قريبة جداً لعين حمرة تدمّع وترفّ، والموبايل منعكس بحدقتها — «عيونك تحرگك من كثر الموبايل؟ 😣» — والكاميرا تطلع من العين |
| 3.2–8.7 ث | المشكلة: شاب بالفراش الساعة 3 الفجر — «الساعة 3 الفجر… وبعدك لازم الموبايل»؛ يتثاوب ويفرك عينه؛ تحرگ · تدمّع · تحمرّ · تتعب؛ «ساعات گبال الشاشة… وبلا راحة 😩» والساعة تركض؛ 💡 «الحل بسيط 👇» |
| 8.7–18.4 ث | الحل (مسحة صفرة): «أول شي: نظارة فلتر الضوء الأزرق 👓» والنظارة تنزل على وجهه؛ «تخفّف الضوء الأزرق اللي يجيك من الشاشة»؛ «وإطارها أسود يخبّل 🖤»؛ «ثاني شي: كل 20 دقيقة… باوع لبعيد 20 ثانية 👀» — يباوع من الشباك، عدّاد 20 ثانية، وهنا بس ترتاح عيونه |
| 18.4–21.7 ث | العرض (وردي): «سعرها؟ 🤔» ملصق «20 ألف بس!» ← سيارة «والتوصيل ببلاش!» |
| 21.7–25 ث | الختام (أصفر): النظارة، الاسم، «💰 20 ألف» «🚚 توصيل ببلاش»، «اطلبها هسة 👇» |

**الأمانة بالكلام:** الأعراض وسببها (ساعات طويلة على الشاشة بلا راحة) حقيقية. النظارة نقول عنها بس إنها تخفّف
الضوء الأزرق، والعيون ترتاح بالفيديو ويا عادة الراحة (20-20-20)، مو من النظارة لحالها.

التصدير: `node ../orin-ad/render/render.mjs --page ../glasses-ad/v2.html --shutter 5` — التعليق الصوتي:
`python3 render/add_vo.py --ad v2 تسجيل.m4a` (النص بملف `vo/script-v2.md`).

**التصدير** (يستخدم محرك `../orin-ad`، شغّل `npm install` هناك أول مرة):

```bash
node ../orin-ad/render/render.mjs --page ../glasses-ad/index.html --shutter 5   # 60 إطار
python3 render/add_vo.py تسجيل.m4a                                              # تعليق صوتي
```

المعاينة: `python3 -m http.server 8000` من جذر المستودع، وافتح `http://localhost:8000/glasses-ad/`.
