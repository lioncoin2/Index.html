# Orin — إعلان موشن جرافيك (30 ثانية)

إعلان عمودي **1080×1920** (مناسب لـ TikTok / Reels / Snapchat / Shorts) لتطبيق **Orin**: مساعد ذكاء اصطناعي للطلاب.
الفيديو الجاهز: `out/orin-ad-9x16-30fps.mp4` و `out/orin-ad-9x16-60fps.mp4`.

## القصة (Storyboard)

| الوقت | المشهد |
|---|---|
| 0–1.5 ث | ساعة تدق `01:59 → 02:00` — «الساعة 2 الفجر…» |
| 1.5–3 ث | «والاختبار الساعة **8 الصبح**» |
| 3–4.5 ث | ثلاث فصول تتكدس — «وباقي **3 فصول** ما ذاكرتها!» |
| 4.5–6 ث | صمت… «لا تشيل هم…» — حلقة المؤقت تتحول إلى شعار Orin |
| 6 ث | ارتطام + دخول الإيقاع — الشعار، Orin، «ذكاء اصطناعي مصمّم للطلاب» |
| 8–11 ث | «يشرح لك أي درس / بأبسط أسلوب» — محادثة عن التمثيل الضوئي |
| 11–14 ث | «يحل المسائل / خطوة بخطوة» — حل `2x + 6 = 14` |
| 14–17 ث | «يلخّص ملفاتك / في ثواني» — تلخيص ملف PDF عن الدولة العباسية |
| 17–20 ث | «ويختبرك / قبل الاختبار» — سؤال اختيار من متعدد + إجابة صحيحة 🎉 |
| 20–22 ث | مونتاج سريع على الإيقاع: رياضيات، فيزياء، كيمياء… |
| 22–24 ث | «كل موادك… في تطبيق واحد» |
| 24–30 ث | الشعار + «ذاكر بذكاء… مو بتعب» + زر «حمّل التطبيق الآن» |

الموسيقى والمؤثرات الصوتية مولّدة برمجياً بالكامل (بدون عينات أو حقوق)، ومتزامنة مع الحركة
عن طريق ملف `out/cues.json` الذي يُستخرج من الـ timeline.

## الإعلان الثاني: مشكلة ← حل (`v2.html`)

الفيديو: `out/orin-ad-v2-9x16-30fps.mp4` و `out/orin-ad-v2-9x16-60fps.mp4`

| الوقت | المشهد |
|---|---|
| 0–2.6 ث | الخطّاف: «وقف! ✋» ثم «4 مشاكل تدمّر مذاكرتك… وحلّها كلها في تطبيق واحد» |
| 2.6–8.2 ث | تقرأ الدرس 3 مرات وما تفهم ← يشرحه لك بأسلوبك لين تفهم |
| 8.2–13.8 ث | ملزمة 80 صفحة والاختبار بكرة ← يلخّص الملزمة في دقيقة |
| 13.8–19.4 ث | علقت في مسألة وما أحد يرد ← معك 24/7 ويحلها خطوة بخطوة |
| 19.4–25 ث | تحس إنك جاهز وتنصدم ← يختبرك قبل الاختبار ويكشف نقاط ضعفك |
| 25–30 ث | «كل مشكلة… لها حل ✅» ثم الشعار وزر التحميل |

كل مشكلة تظهر بأسلوب متوتر (أحمر، تشويش glitch، بدون إيقاع) ثم يُشطب عليها وينزل الإيقاع مع الحل.
التصدير: `node render/render.mjs --page v2.html` (الموسيقى من `render/soundtrack_v2.py`).

## المعاينة في المتصفح

```bash
cd orin-ad
python3 -m http.server 8000     # ثم افتح http://localhost:8000
```

مسطرة التحكم أسفل الصفحة: تشغيل/إيقاف (Space)، سحب للتنقل، وزر 🔊 لتشغيل الصوت.

## التعديل

- **النصوص**: كلها داخل `index.html` (العناوين، الرسائل، الأسئلة، زر الدعوة).
- **التوقيتات**: كائن `T` وجلسات الكتابة `sessions` في `src/timeline.js`.
- **الألوان والخطوط**: متغيرات `:root` في `src/styles.css` (المرجاني `#FF6B56`، الأبيض `#F7F7F7`، الخلفية `#08080A`).
- **الشعار**: معاد بناؤه كـ vector في `src/logo.js` بمطابقة الأيقونة الأصلية، ويمكن رسمه/تدويره جزئياً.

## إعادة التصدير (Render)

المتطلبات: Node 18+ مع Playwright (Chromium)، Python 3 مع `numpy scipy pyloudnorm`، و ffmpeg
(أو `pip install imageio-ffmpeg`).

```bash
npm install                                   # playwright
npx playwright install chromium
pip install numpy scipy pyloudnorm imageio-ffmpeg

node render/render.mjs                        # 60fps + صوت → out/orin-ad-9x16-60fps.mp4
node render/render.mjs --fps 30               # → out/orin-ad-9x16-30fps.mp4
node render/render.mjs --from 8 --to 11 --no-audio --out out/f1.mp4   # جزء فقط
```

الترميز H.264 High + AAC 192k، مصفوفة ألوان BT.709 (حتى يبقى لون العلامة دقيقاً)، والصوت مضبوط على −14 LUFS.
