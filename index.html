طرق تنصيب Claude Flow

دليل سريع لتشغيل claude-flow وتهيئة المشروع

التشغيل بدون تنصيب دائم الطريقة المنصوح بيها

تشغّل أحدث إصدار مباشرة عبر npx دون الحاجة لتنصيب الحزمة على الجهاز. الخيار الأنسب للتجربة السريعة وضمان استخدام آخر نسخة دائمًا. 

# الطريقة المنصوح بيها — بدون تنصيب دائم
npx claude-flow@latest init

التنصيب العام (Global) بديل

تنصيب الحزمة بشكل عام على الجهاز ليصبح الأمر claude-flow متاحًا في أي مكان. مناسب للاستخدام المتكرر. 

# أو global
npm install -g claude-flow
claude-flow init

للمزيد حول Claude Code: code.claude.com/docs
