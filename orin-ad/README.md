# Orin — إعلان موشن جرافيك (30 ثانية)

إعلان عمودي **1080×1920** (مناسب لـ TikTok / Reels / Snapchat / Shorts) لتطبيق **Orin**: مساعد ذكاء اصطناعي للطلاب.
الفيديو الجاهز: `out/orin-ad-9x16-30fps.mp4` و `out/orin-ad-9x16-60fps.mp4`.

## الإعلان الرابع: نفس الطالب، فرق واحد — شاشة مقسومة احترافية (`v4.html`)

الفيديو: `out/orin-ad-v4-9x16-30fps.mp4` و `out/orin-ad-v4-9x16-60fps.mp4` (24.6 ثانية)

هذا الإعلان مبني على **مجموعة أدوات سينمائية مشتركة** (`src/cinema.js` + `src/cinema.css`)
تقدر تُستخدم في أي إعلان قادم:
- **Motion Blur حقيقي**: الرندرر (`render/render.mjs --shutter 5`) يلتقط 5 لقطات فرعية
  لكل فريم ضمن نافذة "شتر" 180° ويدمجها بإضاءة خطّية تقريبية (`render/blend.mjs`) —
  نفس مبدأ الكاميرات الحقيقية، بدل ما كل فريم يطلع حاد 100%.
- **منحنيات حركة مخصّصة** عبر GSAP CustomEase (صار مجاني بترخيص GSAP القياسي).
- **كاميرا يد مهتزة** (handheld) بدالّة عشوائية حتمية — قوية وفوضوية بجهة "بدون Orin"،
  هادئة جداً بجهة "Orin معك".
- **Light sweep / Lens flare / Chromatic-aberration burst** عند اللحظات القوية.
- **تدرّج لوني (Color grading)** مختلف لكل نصف شاشة، ثم يتوحّد بعد المسح.

**القصة:** الشاشة تنقسم نصفين (اليمين "بدون Orin" فوضوي بإضاءة حمراء، اليسار "Orin معك"
هادئ بإضاءة مرجانية) وتعرض 3 جولات متوازية: الوقت، المذاكرة، والنتيجة (5/20 مقابل 18/20) —
ثم مسح مرجاني يمحو الفوضى، ورسالة موحّدة، فالشعار وزر التحميل.

**الصوت مقسوم فعلياً بين القناتين**: كل صوت من جهة "بدون Orin" يذهب لقناة اليمين، وكل صوت
من جهة "Orin معك" لقناة اليسار (`render/soundtrack_v4.py`)، ثم تتوحّد القناتان مع المسح.

التصدير: `node render/render.mjs --page v4.html --shutter 5 --shutterAngle 180`

## الإعلان الخامس: تحدّي 3 أسئلة — إعلان تفاعلي (`v5.html`)

الفيديو: `out/orin-ad-v5-9x16-30fps.mp4` و `out/orin-ad-v5-9x16-60fps.mp4` (34.5 ثانية)

المشاهد **يلعب مع الفيديو**: 3 أسئلة خادعة، ولكل سؤال عدّاد 3 ثواني. المؤقّت نفسه هو حلقة
شعار Orin: عند كل كشف للإجابة تتحوّل الحلقة إلى الشعار وتطير لبطاقة الشرح وتصير صورة Orin.
السؤال الثالث فخ (مسألة المضرب والكرة الشهيرة): الإجابة اللي «أغلب الناس اختاروها» تنكشف
غلط أولاً، وبعدها تنزل الإجابة الصح. والنهاية جدول نتيجة يدفع المشاهد يكتب بالتعليقات.

| الوقت | المشهد |
|---|---|
| 0–2.5 ث | الخطّاف: «3» ضخمة + «أسئلة بس…» + «جاوب قبل ما يخلص الوقت ⏱️» + ملصق «⚠️ أغلب الناس يغلطون بالثالث»، ثم الكاميرا تطير من داخل الرقم 3 |
| 2.5–10 ث | سؤال 1 (سهل 🟢): الريشة والمطرقة بالفراغ ← «يوصلون سوا» |
| 10–17.5 ث | سؤال 2 (متوسط 🟡): 5 مكاين / 5 قطع / 5 دقايق ← «5 دقايق» |
| 17.5–27.5 ث | سؤال 3 (صعب 🔥): المضرب والكرة ← «0.10» تنكشف غلط ❌ ثم «0.05» ✅ |
| 27.5–30.75 ث | «كم جبت؟ 🤔» — 3/3 عبقري 🧠 … 0/3 تحتاج Orin فوراً 💀 + «اكتب نتيجتك بالتعليقات 👇» |
| 30.75–34.5 ث | «Orin يسوّي لك اختبارات زي كذا… من دروسك أنت 🎯» ← الشعار ← زر التحميل |

- بين الأسئلة انتقال **whip pan** (مع الـ motion blur يطلع خط حركة حقيقي)، وشريط تقدّم بأسلوب
  الستوريز أعلى الشاشة، والكاميرا تقترب ببطء (push-in) خلال كل عدّاد وتزيد الرجفة مع التوتر.
- الموسيقى بأسلوب برامج المسابقات (`render/soundtrack_v5.py`): إيقاع خفيف أثناء قراءة السؤال،
  ثم ينقطع ويبدأ تكّ الساعة + نبض القلب بآخر ثانية، ثم «دينق» الإجابة الصحيحة وإيقاع مريح مع
  الشرح؛ صوت «البزر» للفخ، ودرام رول + «با-دم-تس» لسطر «تحتاج Orin فوراً».

التصدير: `node render/render.mjs --page v5.html --shutter 5 --shutterAngle 180`

تسجيل ينضاف بسهولة. النص الكامل ويا التوقيتات وطريقة الإلقاء بملف `vo/v7-script.md`. وبعد التسجيل:


> **ملاحظة تقنية (مهمة لأي إعلان قادم):** Chromium يحتفظ بدقّة الرسم الأولى لأي عنصر مرفوع
> لطبقة مستقلة (`will-change: transform` أو `translate3d`)، فالنص داخل الـ push-in كان يُرسم
> بشكل مختلف قليلاً حسب ترتيب التنقّل بين الفريمات (كل worker يقفز لبداية جزئه). لذلك v5 يستخدم
> تحويلات ثنائية الأبعاد فقط (`gsap.config({ force3D: false })`) ويلغي `will-change` داخل المسرح —
> والنتيجة فريمات متطابقة بت-ببت سواءً رُسمت بالتسلسل أو بالقفز. كذلك الظلال الضبابية الكبيرة
> على النص (`text-shadow`) تحت `scale` تُظهر حواف مربعات، فاستُبدلت بتوهّج `radial-gradient`.

## المعاينة في المتصفح

```bash

```

## التعديل

- **النصوص**: كلها داخل `index.html` (العناوين، الرسائل، الأسئلة، زر الدعوة).
- **التوقيتات**: كائن `T` وجلسات الكتابة `sessions` في `src/timeline.js`.
- **الألوان والخطوط**: متغيرات `:root` في `src/styles.css` (المرجاني `#FF6B56`، الأبيض `#F7F7F7`، الخلفية `#08080A`).
- **الشعار**: معاد بناؤه كـ vector في `src/logo.js` بمطابقة الأيقونة الأصلية، ويمكن رسمه/تدويره جزئياً.

## إعادة التصدير (Render)

المتطلبات: Node 20.9+ (مجرّب على Node 22) مع Playwright (Chromium)، Python 3 مع `numpy scipy pyloudnorm`، و ffmpeg
(أو `pip install imageio-ffmpeg`). لا يحتاج كرت شاشة (GPU)؛ الرندر كله على المعالج.
يعمل على Linux وmacOS، وعلى Windows عن طريق WSL. الإيموجي تُرسم بخط النظام: على Linux ثبّت
`fonts-noto-color-emoji` (نفس شكل الإيموجي في الفيديوهات).

```bash
npm install                                   # playwright + sharp
npx playwright install --with-deps chromium   # --with-deps: مكتبات النظام على Linux
python3 -m venv .venv && source .venv/bin/activate
pip install numpy scipy pyloudnorm imageio-ffmpeg

node render/render.mjs                        # 60fps + صوت → out/orin-ad-9x16-60fps.mp4
node render/render.mjs --fps 30               # → out/orin-ad-9x16-30fps.mp4
node render/render.mjs --from 8 --to 11 --no-audio --out out/f1.mp4   # جزء فقط
```
